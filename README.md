## Getting Started

A standard project usually moves from media import to timeline assembly, editing, finishing, and export.

- Open a project and bring in the required video, audio, and graphics.
- Arrange the imported clips on the timeline, then trim and organize the sequence.
- Isolate subjects or other objects with masking tools when localized adjustments are needed.
- Correct color and match shots throughout the edit.
- Use the multi-camera workflow to select among synchronized angles.
- Complete the project with motion graphics and audio improvements.
- Export the finished sequence using the format expected by the delivery workflow.
